# Projects Manager

## 📝 Descripción
Sistema de gestión de proyectos que permite organizar, administrar y visualizar tareas en una interfaz moderna, accesible y bien estructurada.

## 🚀 Tecnologías utilizadas
  - ⚛️ React
  - 🧪 TypeScript 
  - ⚡ Vite
  - 💨 Tailwind CSS
  - 🌗 ShadCN UI — Sistema de componentes.
  - 🎨 Lucide Icons — Paquete de íconos.
